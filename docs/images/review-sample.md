# A small review, beside the conversation

This file is a public screenshot sample. It contains no workspace or user data.

## A useful review loop

1. Read the change in the Changes tab.
2. Open the current file in the editor.
3. Switch between Preview and Edit.
4. Save deliberately, then keep the conversation moving.

| Check | Status |
| --- | --- |
| Chat stays visible | Ready |
| Source and diff stay separate | Ready |
| Drafts remain protected | Ready |

Small controls. Clear boundaries. Room to actually work.
