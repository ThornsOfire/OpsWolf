# OpsWolf documentation

A file explorer, editor and change review beside your Codex chat. Start with the guide below; this is still a developer alpha without a public OpsWolf installer.

- **[Editor fork — current features and build guide](README.md):** our editor additions, build steps, current limits, and wishlist ;3
- **[Portable Windows pilot](docs/editor/portable.md):** temporary test downloads, simple launch instructions and the first-machine checklist; no published alpha Release yet.
- **[Required tools and optional downloads](README.md#what-you-actually-need):** start small; build tools, desktop automation and plugins serve different jobs.
- **[Upstream Code-Codex v0.6.0 release notes](releases/README.md)** cover the upstream changes and their verification scope.
- **[Original project — English translation](README.upstream.en.md):** a translation of the archived upstream overview, including its original installation and plugin documentation.
- **[Original project — preserved Chinese original](README.zh-CN.md):** the unchanged source document for the translation.

OpsWolf is based on [Rice-dog/code-codex](https://github.com/Rice-dog/code-codex). Use the editor fork guide for OpsWolf source setup. The alpha.18 source adds personal Rain presets and saved Position #1 / Position #2 blend choices, while keeping editor Refresh and reversible Changes-list clearing. See the [Rain settings guide](docs/editor/code-rain-integration.md#presets-and-blend-settings).
