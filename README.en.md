# OpsWolf documentation

A file explorer, editor and change review beside your Codex chat. Start with the guide below; this is still a developer alpha without a public OpsWolf installer.

- **[Editor fork — current features and build guide](README.md):** our editor additions, build steps, current limits, and wishlist ;3
- **[Required tools and optional downloads](README.md#what-you-actually-need):** start small; build tools, desktop automation and plugins serve different jobs.
- **[Upstream Code-Codex v0.6.0 release notes](https://github.com/ThornsOfire/OpsWolf/blob/c5224de0f8c6fbebbad6dc5d042598103fd35754/releases/README.md)** cover the upstream changes and their verification scope.
- **[Original project — English translation](https://github.com/ThornsOfire/OpsWolf/blob/c5224de0f8c6fbebbad6dc5d042598103fd35754/README.upstream.en.md):** a translation of the archived upstream overview, including its original installation and plugin documentation.
- **[Original project — preserved Chinese original](https://github.com/ThornsOfire/OpsWolf/blob/c5224de0f8c6fbebbad6dc5d042598103fd35754/README.zh-CN.md):** the unchanged source document for the translation.

OpsWolf is based on [Rice-dog/code-codex](https://github.com/Rice-dog/code-codex). Use the editor fork guide for OpsWolf source setup. The alpha.15 source includes the Code-Codex v0.6.0 integration and Rain worker rendering. [Qualification notes](https://github.com/ThornsOfire/OpsWolf/blob/c5224de0f8c6fbebbad6dc5d042598103fd35754/docs/editor/upstream-integration.md#alpha15-qualification) distinguish passed local checks, owner observations and remaining live/fresh-install checks.
